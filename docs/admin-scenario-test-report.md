## 2. 확인된 UX 피드백

### P0 — 실제 영수증 보관 및 OCR 처리

현재 업로드한 사진은 브라우저 로컬 저장소에 저장되는 프로토타입이다. 기존 예시 영수증은 원본 사진이 없어 상세 화면에 안내용 플레이스홀더가 표시된다.

**영향:** 관리자가 다른 휴대폰이나 PC에서 영수증 원본을 확인할 수 없고, 브라우저 데이터 삭제 시 증빙이 사라질 수 있다.

**권장 개선:**

1. 사진을 S3/Vercel Blob 등 객체 스토리지에 저장한다.
2. `Receipt` 레코드에 이미지 URL, 촬영 시각, 업로드 사용자, OCR 상태를 저장한다.
3. OCR 워커가 업체·품목·수량·단가·총액을 추출하고 신뢰도를 기록한다.
4. 원본 사진이 없는 과거 기록은 `원본 없음`으로 분리 표시한다.

### P1 — 영수증 검토 단계 강화

업로드 후 현재는 `OCR 분석 중` 상태가 날짜 목록에 표시되지만, 관리자가 행 단위로 값 수정·확정하는 전용 검토 화면이 필요하다.

**권장 개선:**

- 원본 사진과 추출 품목 표를 좌우 또는 상하로 함께 표시
- 총액 대 품목 합계의 차이 금액 표시
- 원문 품목명 → 표준 품목 연결/새 품목 생성
- `확정` 전에는 재고와 비용 집계에 반영하지 않기
- 검토자·확정 시각·수정 이력 기록

### P1 — 날짜 탐색 기능

날짜별 목록은 읽기 쉽지만, 영수증이 누적되면 특정 날짜나 기간을 찾기 어려워진다.

**권장 개선:**

- 상단에 이번 주/이번 달/사용자 지정 기간 필터
- 날짜 캘린더 또는 날짜 점프
- 업체·상태(검토 필요/확정)·운영 영역(홀/주방) 필터
- 해당 날짜의 거래 건수와 총액을 고정 요약으로 표시

### P2 — 모바일 발주 등록 버튼의 의미 전달

홈 상단 버튼은 화면 공간을 위해 `+` 아이콘으로 축약되어 있다. 익숙한 사용자는 빠르지만 첫 사용자는 버튼 목적을 바로 알기 어려울 수 있다.

**권장 개선:**

- 첫 진입 또는 온보딩 중에는 `영수증 등록` 레이블을 함께 노출
- 툴팁 또는 1회성 안내 제공
- 영수증 목록 화면에는 항상 텍스트가 있는 `+ 영수증 등록` 버튼 유지

### P2 — 업체 상세의 발주일 영수증 연결

업체 상세에서는 날짜별 거래 금액을 확인할 수 있다. 다음 단계에서는 각 날짜 행에서 해당 영수증 원본과 품목 행으로 직접 들어갈 수 있어야 한다.
