## 테스트로 확인한 개선점

### 정상 동작

- 필터 상태는 화면을 다시 그린 뒤에도 적용되어, 마감 전 미확정 영수증 처리 흐름에 적합하다.
- `검토 필요 → 확정` 전환 뒤 목록 결과가 즉시 바뀌어 관리자가 완료 여부를 확인하기 쉽다.
- 주방·홀 품목을 별도 흐름으로 탐색하고, 품목 상세의 발주 이력까지 연결된다.
- 모바일 폭에서 가로 스크롤 없이 목록·상세·다이얼로그가 표시된다.

### 다음 검증/개발 필요 사항

1. 실제 사진 파일 업로드와 OCR 응답은 현재 브라우저 로컬 저장소 프로토타입이므로, 운영 DB·이미지 스토리지·OCR API가 연결된 환경에서 재검증해야 한다.
2. 품목 금액 수정 시 총액 불일치 경고와 금액 자동 합산 표시가 필요하다.
3. `확정` 시 재고 입고 원장과 업체·품목별 월간 집계가 실제 DB 트랜잭션으로 함께 반영되는지 검증해야 한다.
4. 업체 상세의 과거 거래일마다 실제 영수증 원본이 존재하는지, 원본 없음 상태가 분명히 구분되는지 확인해야 한다.
5. 권한별 테스트가 필요하다. 직원은 업로드만, 관리자는 확정·금액 수정·재고 조정을 수행하도록 제한해야 한다.
