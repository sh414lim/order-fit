# OrderFit 관리자 사용자 시나리오

## 1. 관리자 역할과 운영 목표

관리자는 영수증을 확인해 발주 데이터를 확정하고, 업체·품목·재고·비용을 통합 관리한다. 핵심 목표는 다음 네 가지다.

1. 누락 없는 발주 기록을 만든다.
2. 발주 금액과 품목 단가의 이상 변동을 빠르게 찾는다.
3. 주방 식자재와 홀 운영 소모품을 구분해 부족 재고를 예방한다.
4. 월말에 업체별 거래와 품목별 비용을 근거로 의사결정한다.

## 2. 사용자 프로필

| 항목 | 내용 |
| --- | --- |
| 사용자 | 김민지, 한결 다이닝 점장 겸 발주 관리자 |
| 업무 환경 | 매장·주방을 오가며 휴대폰으로 영수증을 확인, 주 단위로 PC에서 비용을 검토 |
| 권한 | 영수증 확정, 업체·품목 마스터 수정, 재고 조정, 리포트 조회 |
| 주요 고민 | 영수증 누락, 다른 표기로 인한 품목 중복, 원가 상승의 늦은 발견, 부족 재고 |

## 3. 대표 시나리오 A — 당일 영수증 등록 및 발주 확정

### 상황

오전 10시, `푸른식자재` 배송이 도착한다. 주방 직원이 수령한 영수증을 관리자에게 전달한다. 관리자는 이동 중 휴대폰으로 영수증을 등록한다.

### 목표

배송 당일에 영수증을 발주 데이터로 확정하고, 해당 품목을 주방 재고에 반영한다.

| 단계 | 관리자 행동 | 시스템 동작 | 확인/판단 기준 |
| --- | --- | --- | --- |
| 1 | 홈 화면의 `+` 버튼을 누른다. | 영수증 등록 화면을 연다. | 한 손 조작으로 접근 가능해야 한다. |
| 2 | 발주 날짜와 업체를 선택하고 영수증 사진을 촬영·업로드한다. | 원본 사진을 저장하고 OCR 작업을 시작한다. | 업로드 실패 시 재시도와 임시보관을 제공한다. |
| 3 | OCR 결과에서 업체명, 총액, 품목·수량·단가를 검토한다. | 낮은 신뢰도 항목, 행 합계와 총액 불일치를 강조한다. | 총액이 영수증과 일치하는지 확인한다. |
| 4 | `국산 양파 20KG`를 표준 품목 `양파`로 연결한다. | 다음 동일 표기를 자동 연결하도록 별칭 규칙을 저장한다. | 기존 품목인지 신규 품목인지 판단한다. |
| 5 | 발주 내역을 확정한다. | 날짜별 영수증, 업체별 거래, 품목별 비용에 반영하고 재고 입고 거래를 생성한다. | 재고가 정상적으로 증가했는지 확인한다. |

### 예외 처리

- 업체가 OCR로 인식되지 않으면 최근 이용 업체를 제안하고, `기타 업체`를 새 거래처로 전환한다.
- 총액이 품목 합계와 다르면 `확정` 버튼을 비활성화하거나 차이 금액을 명시한다.
- 같은 날짜·같은 업체·유사 금액 영수증이 있으면 중복 가능성을 경고한다.
- 사진이 흐리면 재촬영을 권하고, 관리자 직접 입력으로도 확정할 수 있어야 한다.

### 완료 조건

- 날짜별 영수증 목록에 해당 거래가 표시된다.
- 주방 `양파`, `대파` 등의 재고가 입고 수량만큼 증가한다.
- 푸른식자재의 월 누적금액과 거래 건수가 갱신된다.

## 4. 대표 시나리오 B — 날짜별 발주 품목 및 영수증 원본 확인

### 상황

오후에 주방장이 “지난주 목요일에 식용유를 몇 통 주문했는지” 묻는다.

### 목표

사진 원본까지 확인하면서 특정 날짜의 발주 품목과 금액을 1분 안에 답한다.

1. 관리자는 하단 메뉴에서 `영수증`을 선택한다.
2. 날짜별 발주 목록에서 `2026.08.05`를 찾는다.
3. 해당 날짜의 거래 건수와 합계 금액을 먼저 확인한다.
4. `그린패키지` 영수증을 선택한다.
5. 원본 사진, 총 발주금액, 품목 행을 확인한다.
6. `식용유 18L`, 수량·단가·품목 금액을 주방장에게 전달한다.

### 화면에 반드시 노출할 정보

| 목록 화면 | 영수증 상세 화면 |
| --- | --- |
| 발주 날짜, 해당 일 거래 건수, 일 합계 | 영수증 원본 이미지 |
| 업체명, 영수증별 합계 | 업체·발주 날짜·확정 상태 |
| 대표 발주 품목 2~3개 | 품목명, 규격, 수량, 단가, 품목 금액 |
| 검토 필요 여부 | OCR 수정 이력, 확정자, 확정 시각 |

## 5. 대표 시나리오 C — 홀/주방 재고 분리 운영

### 상황

금요일 저녁 예약이 많다. 주방은 식자재, 홀은 포장 용기와 냅킨을 각각 확인해야 한다.

### 목표

재고 성격이 다른 두 운영 영역을 혼동하지 않고 우선 발주 대상을 결정한다.

| 단계 | 주방 영역 | 홀 영역 |
| --- | --- | --- |
| 1 | `품목` 메뉴에서 `주방` 탭을 연다. | 같은 화면에서 `홀` 탭을 연다. |
| 2 | 최소재고보다 낮은 양파·대파를 확인한다. | 재주문이 필요한 냅킨·포장용기를 확인한다. |
| 3 | 사용량과 예상 소진일을 본다. | 행사/예약을 고려해 안전재고를 판단한다. |
| 4 | 식자재 업체에 주문할 품목을 준비한다. | 포장재 업체에 주문할 품목을 준비한다. |

### 관리자 판단 규칙

- 주방: `현재고 ÷ 일평균 사용량`이 납기일보다 짧으면 발주 추천 대상으로 표시한다.
- 홀: 예약·배달 예상량을 반영해 최소재고보다 여유 있게 주문할 수 있어야 한다.
- 품목은 하나의 운영 영역에 기본 소속되지만, 공용 품목은 두 영역에 각각 배분 비율을 설정할 수 있다.

## 6. 대표 시나리오 D — 단가 상승 확인 및 업체 비교

### 상황

대시보드에서 `한우 등심 단가 12% 상승` 알림을 받는다.

### 목표

단가 변동의 근거를 확인하고, 업체 변경·협상·메뉴 원가 검토 여부를 결정한다.

1. 알림에서 `한우 등심` 품목 상세로 진입한다.
2. 최근 단가, 평균 단가, 날짜별 거래 이력을 확인한다.
3. 특정 발주일의 업체와 수량, 금액, 영수증 원본을 확인한다.
4. 대체 업체의 최근 단가와 최소 주문 단위를 비교한다.
5. 다음 중 하나를 기록한다: 기존 업체 유지, 단가 협상 요청, 대체 업체 테스트, 메뉴 원가 재검토.

### 상세 화면의 필수 데이터

- 이번 달 발주금액, 거래 건수, 평균 단가, 최근 단가
- 날짜별 수량·단가·품목 금액·거래처
- 최근 3/6개월 단가 추이
- 업체별 비교: 단가, 납기, 최소주문금액, 최근 불량/반품 이력
- 관련 영수증 원본 및 수정 이력

## 7. 대표 시나리오 E — 월말 비용 검토 및 정산

### 상황

월말 정산 전, 관리자는 이번 달 식자재비가 예산을 넘었는지 확인해야 한다.

### 목표

업체·운영 영역·품목 관점으로 비용 증가 원인을 찾고 다음 달의 발주 기준을 세운다.

| 검토 순서 | 관리자 질문 | 필요한 화면/지표 |
| --- | --- | --- |
| 1 | 이번 달 총 발주액은 예산 대비 어떤가? | 대시보드 월간 총액, 예산 대비율 |
| 2 | 홀과 주방 중 어디서 증가했는가? | 영역별 발주금액, 전월 증감 |
| 3 | 어떤 업체의 거래가 늘었는가? | 업체별 누적금액, 거래 건수 |
| 4 | 어떤 품목이 원인인가? | 품목별 구매금액·수량·단가 상승률 |
| 5 | 증빙이 충분한가? | 날짜별 영수증, 미확정/누락 영수증 |

### 산출물

- 업체별 발주금액 보고서
- 홀/주방별 발주비 비교
- 단가 상승 상위 품목 목록
- 미확정 영수증 및 누락 가능 거래 목록
- 다음 달 최소재고·발주업체 조정안

## 8. 알림 설계

| 우선순위 | 알림 | 관리자 행동 |
| --- | --- | --- |
| 높음 | 최소재고 이하 또는 납기 전 소진 예상 | 품목 상세에서 발주 요청 생성 |
| 높음 | OCR 총액 불일치 / 미확정 영수증 | 영수증 검토·수정·확정 |
| 보통 | 최근 평균 대비 단가 10% 이상 상승 | 단가 이력과 업체 비교 확인 |
| 보통 | 동일 업체·유사 금액의 중복 영수증 | 원본 사진 비교 후 중복 처리 |
| 낮음 | 한 달간 발주가 없는 주요 품목 | 메뉴 변경 또는 품목 상태 확인 |

## 9. 관리자 경험 원칙

- 모바일에서는 `확인 → 결정 → 기록`의 단일 행동이 한 화면에서 끝나야 한다.
- 목록에는 결정을 위한 요약만, 상세에는 원본과 모든 거래 근거를 제공한다.
- 확정 전 데이터와 확정 후 데이터의 상태를 명확히 구분한다.
- 금액·수량·날짜·업체는 어디서나 같은 형식으로 표시한다.
- 영수증 사진 원본은 삭제나 수정 전에 항상 열람 가능해야 한다.
- 중요한 변경(총액 수정, 재고 조정, 업체 변경)은 감사 로그에 남긴다.

## 10. 성공 지표

| 지표 | 1차 목표 |
| --- | --- |
| 영수증 당일 등록률 | 95% 이상 |
| OCR 후 관리자 수정 없이 확정되는 품목 행 비율 | 70% 이상 |
| 발주 영수증 누락률 | 2% 이하 |
| 부족 재고로 인한 긴급 구매 건수 | 월 20% 감소 |
| 월말 비용 검토 소요 시간 | 2시간에서 30분 이내 |
